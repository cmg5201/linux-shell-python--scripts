# Linux自动化运维脚本与Python商品管理系统

## 📌 项目简介
本仓库包含多个独立的实战项目：
1. Shell自动化运维脚本（系统信息与资源监控,备份与归档,服务与进程管理,日志与清理等）
2. Python面向对象商品管理系统（基于JSON文件的数据持久化）

## 🛠️ 技术栈
- Linux (CentOS 7/8, Ubuntu)
- Shell (grep, awk, sed, crontab)
- Python 3 (面向对象, JSON)
